# Python-SQL-Frontend-Visualization

A Python data visualization project featuring a **Streamlit** web application (**Student Marks Analyzer**) and a **Jupyter Notebook**.

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Samprit01/Python-SQL-Frontend-Visualization.git
cd Python-SQL-Frontend-Visualization
```

### 2. Create and Activate a Virtual Environment (Recommended)

```bash
python -m venv venv

# On Windows:
venv\Scripts\activate

# On macOS/Linux:
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
pip install sqlalchemy pymysql matplotlib
```

### 4. Run the Streamlit App

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal (typically `http://localhost:8501`) in your browser.

### 5. Run the Jupyter Notebook (Optional)

```bash
jupyter notebook
```

Open `work.ipynb` from the browser interface to run the notebook cells.
